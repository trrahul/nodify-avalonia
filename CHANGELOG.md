# Changelog

All notable changes to Nodify.Avalonia are documented in this file.

## 2.0.0

Major release: Avalonia 12 upgrade, an input-system rewrite, and a parity pass against upstream
[miroiu/nodify](https://github.com/miroiu/nodify).

### Changed
- Upgraded from Avalonia 11 to Avalonia **12.0.5**.
- Retargeted from net7.0 to **net8.0**.
- Rewrote the input system on the miroiu v7 `InputProcessor` architecture.
